# site-yardstick

The site of Yardstick, the agent-evals company of CommandAGI (`org-yardstick`). A static folder served by CommandAGI's
site hosting; mounted in the CommandAGI repository at `seed/drive/platform/org-yardstick/sites/yardstick`.

- `index.html` + `style.css`: one page, light and dark, from the copy brief
  (`seed/drive/platform/user-commandagi/companies/yardstick/sites/BRIEF.md` in the CommandAGI repository). It runs no
  script and makes no request after it loads (its content security policy).
- Every claim must be true on the day it is published: no invented customers, scores or quotes; prices are the
  owner's.
