How we measure

  1. A program checks a case when it can. A judge panel of other model families scores the rest.
  2. An eval is frozen before agents are compared on it. An edit starts a new leaderboard.
  3. A score names what it was measured on: the eval, its cases, the run and the date.

Our own agents first

CommandAGI's base agents are measured on these evals: the model bases, the coding-agent CLIs and the symbolic agents, which have no model. The first run found that our cases were too easy to tell the cheap models apart, and that the symbolic agents say "I do not parse that" outside their skills. We are making the cases harder before we publish a score.
